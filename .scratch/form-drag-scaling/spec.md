# 形式阻力按速度三次方缩放

Status: ready-for-agent

## Problem Statement

在 Stonefish 中模拟 AUV 的使用者发现：同一套 `quadratic_drag` 系数只在约 1 m/s 时给出正确阻力。0.5 m/s 时阻力只有应有值的一半，滑行距离明显偏长；2 m/s 时阻力是应有值的两倍，最高航速被压低。原因是形式阻力（form drag）按相对速度的**三次方**累积，而标准阻力方程是二次方；这使得 `Cd` 事实上带有速度量纲，系数无法在速度区间内复用，也无法与文献或实验数据对齐。

## Solution

逐面形式阻力只累积**投影面积**（乘以法向速度分量），把速度的二次方留给最后的 `0.5·ρ·Cd` 缩放。修正后，无水流直线运动时逐面求和恒等于 `A_proj`，整体退化为标准阻力方程 `0.5·ρ·Cd·A_proj·|v|·v`。完全浸没与跨水面两条阻尼路径同步修正；理论文档补上公式。

## User Stories

1. 作为海洋机器人研究者，我希望仿真阻力随相对速度的平方增长，以便在某一速度下标定的阻力系数在整个速度区间内保持有效。
2. 作为调参使用者，我希望 `quadratic_drag` 是无量纲、与速度无关的系数，以便在载具与场景之间迁移数值。
3. 作为低速 AUV（0.2–0.5 m/s）使用者，我希望低速阻尼正确，以便滑行距离与定点悬停行为接近真实。
4. 作为高速载具（2–3 m/s）使用者，我希望阻力不被高估，以便仿真最高航速不被压低。
5. 作为带海流场景的使用者，我希望逐面阻力仍使用各面局部相对速度，以便载具进入海流时自然偏转而不是整体平移。
6. 作为完全浸没刚体的使用者，我希望修正落在 submerged 阻尼路径上，以便水下航行器的核心工况正确。
7. 作为浮体或跨水面刚体的使用者，我希望同一修正落在 surface 阻尼路径上，以便水线附近行为与全浸没一致。
8. 作为复合体（compound）使用者，我希望修正自动作用于每个外部部件，以便不需要额外配置。
9. 作为维护者，我希望有一条修复前失败、修复后通过的回归测试，以便该缺陷不会再次引入。
10. 作为维护者，我希望测试直接对照标准阻力方程断言，以便物理契约被显式固定下来，而不是对照当前实现。
11. 作为维护者，我希望测试覆盖 submerged 与 surface 两条重复代码路径，以便二者不再漂移。
12. 作为维护者，我希望测试在无窗口、无 GPU 的环境下运行，以便可以放进 CI。
13. 作为审查者，我希望改动是最小化的删除，以便浮力、附加质量、皮肤摩擦的既有经验标定不受影响。
14. 作为文档读者，我希望理论页给出逐面阻力公式与系数含义，以便把 Stonefish 的模型与标准阻力方程对应起来。
15. 作为使用者，我希望变更日志说明阻力行为已改变，以便判断是否需要重新标定。
16. 作为使用者，我希望 `viscous_drag` / `quadratic_drag` 的 XML 与 C++ 接口保持不变，以便现有场景文件继续加载。
17. 作为使用者，我希望零速度时阻力严格为零且不产生 NaN，以便静止状态数值稳定。
18. 作为使用者，我希望阻力产生的力矩使用同一修正后的逐面力，以便旋转阻尼与平移阻尼一致。
19. 作为球体等曲面体使用者，我希望修正后的结果与投影面积约定一致（球体 `A_proj = πR²`），以便自动估计的系数可解释。
20. 作为上游贡献者，我希望该修复能独立提交，以便向上游 `patrykcieslak/stonefish` 反馈。

## Implementation Decisions

### 核心改动

两条阻尼路径（完全浸没、跨水面）中的逐面形式阻力累加项，从

```
quadratic = vc * |vc| * (-vc_n) * A
```

改为

```
quadratic = vc * (-vc_n) * A
```

即删除多出的速度模长因子。该块内因此不再需要的速度模长局部变量一并删除。以上片段来自本次分析的定量验算，精确表达该决定。

### 为什么不是恢复旧形式

1.4 之前（以及当前空气动力学路径）使用法向形式 `vn * |vn| * A`。它量纲正确，但对曲面网格只给出投影面积公式的一半：球体上 `∫cos²θ·n dA = A_proj/2`，与自动系数采用的投影面积约定冲突。因此**不**采用该形式。

### 保持不变的部分

- 入流判据（法向分量小于负阈值）不变。它承担「只累加迎流面 = 投影面积」的语义。
- `CorrectHydrodynamicForces` 中的 `0.5·ρ` 缩放与方向性系数混合逻辑不变；本次修复只让被缩放的量回到正确量纲。
- 不新增、不修改公共接口；函数签名不变；XML schema 不变。
- 复合体无需单独改动：其每个外部部件走同一逐面计算。

### 文档

- 理论页 Drag 小节补出公式、投影面积恒等式，以及「无水流直线运动时退化为标准阻力方程」的说明。
- 变更日志在 1.6 段落新增一条「修正形式阻力按速度三次方而非平方缩放」。

## Testing Decisions

好测试只断言可观察的物理行为（力的大小与方向随速度、几何的变化），不断言循环结构或内部变量。

### 接缝

使用既有公共静态函数，不新增生产代码接缝：

- `SolidEntity::ComputeHydrodynamicForcesSubmerged`
- `SolidEntity::ComputeHydrodynamicForcesSurface`
- `SolidEntity::CorrectHydrodynamicForces`

三者均为 `public static`，不需要实体实例、不需要 `SimulationApp`。`Ocean` 构造函数不依赖 `SimulationApp`；`waves = 0` 时深度查询走平面分支，流体速度返回零向量。`PlainMesh` 可手工填充顶点与面，直接作为输入。

### 夹具

- 手工构造 `PlainMesh`：单位立方体、UV 球。
- 静水 `Ocean`：`waves = 0`，海流关闭。
- 变换取单位阵，刚体沿 +X 平动，角速度为零。

### 断言

- 力模长等于 `0.5·ρ·Cd·A_proj·U²`（立方体精确；球体容差约 1%，来自网格离散）。
- 方向与相对速度相反。
- 速度缩放：`F(2U)/F(U) ≈ 4`、`F(0.5U)/F(U) ≈ 0.25`。这一条在当前代码上给出 2 与 0.5，是回归的判别性断言。
- 对称体绕质心的阻力矩为零（或与解析值一致）。
- 全浸没立方体在两条路径上给出一致结果（surface 路径用于捕捉重复代码漂移）。

### 现有测试的对照物

本仓库没有断言式测试，`Tests/*` 是 `BUILD_TESTS` 下的交互式演示程序。新测试沿用「`Tests/` 下独立可执行目标、链接测试版库」的约定，但为无窗口、失败时返回非零码的纯命令行程序。仓库无测试框架，使用标准断言加失败计数，不引入 Catch2/GTest 依赖。

## Out of Scope

- 皮肤摩擦项缺少一个速度因子（量纲为 kg/s 而非 N）的问题。会显著改变阻尼量级，需单独决策。
- 空气动力学路径沿用旧法向形式（量纲正确，但曲面体相对投影面积约定偏小一半）。
- 附加质量、浮力、波浪力模型。
- 自动估计 `Cd` / `Cf` 的数值与形状近似逻辑。
- 复合体阻力系数应用问题（上游 issue #63）——已在 1.5 修复。
- 向上游提交 PR 的流程本身。
