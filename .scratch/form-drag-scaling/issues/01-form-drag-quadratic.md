# 01: 形式阻力按相对速度二次方缩放

**What to build:** 完全浸没与跨水面两条阻尼路径的逐面形式阻力都退化为标准阻力方程 `0.5·ρ·Cd·A_proj·|v|·v`（无水流、直线运动时），并配一条无窗口、断言式的回归测试证明该行为。测试必须先红后绿。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 逐面形式阻力累加项不再包含速度模长因子，两条路径同步修改
- [ ] 新增无窗口断言式测试程序，随 `BUILD_TESTS` 构建，失败时返回非零退出码
- [ ] 测试断言：单位立方体、ρ=1000、Cd=1 时，U=0.5/1/2 m/s 的阻力模长为 125/500/2000 N，方向与相对速度相反
- [ ] 测试断言：半径 1 m 球体在 U=2 m/s 时阻力与 `0.5·ρ·Cd·πR²·U²` 相差不超过 1%
- [ ] 测试断言：速度缩放 `F(2U)/F(U)≈4`、`F(0.5U)/F(U)≈0.25`
- [ ] 测试断言：全浸没立方体在 surface 与 submerged 两条路径上给出一致结果
- [ ] 修正前的代码上测试失败（红），修正后通过（绿）
- [ ] 不改变公共接口、XML schema，也不改变浮力、附加质量、皮肤摩擦的既有行为
